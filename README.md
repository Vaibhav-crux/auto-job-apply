## Create Environment
`python -m venv .venv`

## Activate Environment
`.\venv\Scripts\Activate.ps1`

## Install Requiremets
`pip install -r requirements.txt`

## Scripts to execute automation for different platforms
- `python naukri_script.py`

- `python linkedIn_scripts.py`

- `python indeed_script.py`
